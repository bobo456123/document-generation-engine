## 功能简介

将状态为“待处理”或“跟进中”的线索转化为客户，并可选择同时创建关联项目。流程最终回写线索状态并保存线索转换记录。

## 前置条件

- 线索状态必须是 `pending` 或 `following`。
- 必须完成客户处理：关联已有客户，或创建新客户。
- 创建项目是可选步骤。

## 操作步骤

1. 在符合条件的线索上打开“转化”操作。
2. 在客户步骤选择“关联已有客户”或“创建新客户”，填写并提交所需信息。
3. 如不需要创建项目，选择“跳过项目，仅转客户”；否则进入下一步填写项目信息。
4. 在项目步骤提交项目，或跳过项目。
5. 系统将线索状态更新为 `converted`，随后写入包含线索、客户及可选项目标识的转换记录。
6. 只有转换记录返回成功状态后，页面才显示“转换成功”并关闭抽屉。

## 异常与注意事项

- 关联已有客户时，系统会尝试回写客户的 `lookupLead`；此更新失败不会阻断主转换流程。
- 未取得客户 ID 时，转换立即停止，并要求重新选择客户。
- 项目创建失败时，客户可能已经处理完成；页面停留在项目步骤，用户可稍后手工补建项目。
- 线索状态或转换记录更新失败时，不显示转换成功，需重试。
- 源码注释记录了状态枚举与列表筛选值可能不一致，此项必须由后端或 CRM 研发确认。
