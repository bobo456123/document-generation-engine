# 安全规范

## 凭证

- API Key、App Secret、访问令牌、Cookie 和 Authorization Header 只能通过环境变量或密钥管理器注入。
- 文档、配置、测试夹具、日志和提交历史不得包含真实凭证。
- 示例使用明确占位符，不得使用曾经真实有效的值。

## 源码与路径

- 被分析项目只读访问，默认不得修改其文件或 Git 状态。
- 仓库文档不得记录真实的本机用户绝对路径；使用角色化描述或占位路径。
- 发送源码摘录到外部模型前必须确认企业合规范围；未确认时使用证据模板。

## 截图与外部发布

- 截图在导入前由人工完成脱敏；格式和尺寸校验不代表内容安全。
- 发布只允许指向用户明确授权的测试知识空间，生产发布不在当前范围。
- 外部权限、知识空间和模型服务状态可能变化，每次真实操作前重新预检。

## 日志与持久化

- 事实进入业务快照、SQLite、模型输入和错误记录前执行统一脱敏。
- 第三方 SDK 的原始请求对象和响应不得直接输出；只保留裁剪后的业务错误分类。
