## 固定评测口径

- 关键路径关联覆盖率：金标关键节点中，能够定位到源码证据的节点数 / 金标关键节点总数。
- 事实准确率：研发评审判定正确的文档事实数 / 已评审文档事实总数。
- 步骤覆盖率：文档覆盖的金标操作步骤数 / 金标操作步骤总数。
- 无证据陈述数：非 `inferred` 且没有有效证据 ID 的陈述数量。
- 人工修改项数：评审记录中标记为错误、遗漏、措辞调整或冲突的独立项数量。
- 人工修改耗时：从评审开始到形成可批准修订的人工分钟数。
- 发布成功率：成功发布次数 / 实际发布尝试次数；首次与重复发布分开统计。
- 人工映射数量：来源为 `MANUAL_INPUT` 的映射事实数量。

以上口径在人工评测前固定；后续不能因结果不理想而修改分母。
