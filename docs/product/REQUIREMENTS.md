# 当前有效需求

本文描述 `v0.1.1` 当前已经实现并通过质量门的能力。未来候选能力见[当前路线图](../current/ROADMAP.md)，历史需求原文见 [MVP PRD](../milestones/v0.1-mvp/PRD.md)。

## CLI 与工作空间

- 本地开发可以把源码入口链接为全局 `bizdoc` 命令；当前入口通过 `tsx` 运行仓库源码，不作为已发布的 npm 包。
- `init` 默认在当前目录创建 `.bizdoc`；后续命令从当前目录向上发现最近的工作空间，显式目录参数继续兼容一个迁移周期。
- 支持列出业务功能、业务文档和工作空间状态；交互终端可按名称选择功能、文档和步骤，自动化仍可使用稳定 ID 和 JSON 输出。
- `doctor` 只检查项目已启用的 AI 或飞书配置和凭证；未启用的外部服务不应阻塞本地模板流程。
- macOS 支持将 AI 与飞书凭证主动保存到系统钥匙串；环境变量优先，非 macOS 和 CI 使用环境变量。
- 凭证查看命令只显示来源，不输出真实值；删除钥匙串凭证不得改变环境变量。

## 输入与分析

- 接受一个 Spring Boot 后端和一个 Vue、React 或 Umi 前端源码目录。
- 只读扫描源码，不修改被分析项目。
- 提取页面、操作、请求、Controller、DTO、校验、Service、数据访问和状态变化等事实。
- 将前后端事实关联为业务功能，并保留来源文件、Commit、行号、证据和置信度。
- 对无法可靠关联或解析的内容显式记录，不静默提升为已验证事实。

## 文档生成与修订

- 从不可变业务快照生成平台无关的结构化文档模型和 Markdown。
- 支持证据模板与配置的真实 AI；未配置模型时不得冒充 AI 推理已经完成。
- 模型输出必须通过结构和证据 ID 校验，并包含阻塞式人工审核项。
- 配置 AI 后默认使用真实 AI；用户可显式选择证据模板，未配置 AI 时也默认使用模板。
- 新文档保存稳定的所属系统和经用户确认的业务模块；技术 Controller 名称不得直接冒充业务模块。
- 已审核且缺少分类或带空白/“未分类”占位模块的 v0.1 旧文档可复制为增加系统/业务模块和阻塞式归类确认项的待审核修订；正文、证据、截图和旧修订保持不变，分类修订不得自动继承批准状态。
- 旧文档归类只在本地执行且不调用 AI 或飞书；引用的截图记录或文件缺失时不得创建新修订。
- 每次生成或添加截图产生新修订，不覆盖旧修订。

## 截图、审核与发布

- 支持导入已经人工脱敏的 PNG、JPEG 或 WebP，并关联到指定操作步骤；macOS 可通过系统文件选择器或交互截图直接导入。
- 系统截图不负责登录、页面遍历或内容脱敏，执行前必须由用户确认当前页面已脱敏。
- 支持本机预览证据、正文和截图。
- 只有最新修订已明确批准且没有未解决的 blocking 项时才能发布。
- 支持把文档、原生表格和图片幂等发布到已授权的飞书测试知识空间。
- 同一截图资源被多个操作步骤引用时，必须按截图出现位置分别创建并绑定飞书图片块，不得因资源去重导致空白图片。
- 飞书目录固定为可选托管根下的“系统/业务模块/文档”；系统和模块节点通过稳定映射幂等复用。
- 既有根目录文档迁移到业务模块时保留原节点和链接；缺失、空白或“未分类”模块均视为没有有效业务分类，必须先完成分类修订和人工批准，并在任何飞书凭证读取或网络访问前阻塞发布。
- 重复发布更新既有节点；远端更新失败时不得清空原有正文。
- 按索引删除旧正文属于不可安全重放操作；临时网络或服务失败时不得自动重试该请求。

## 数据与安全

- SQLite 保存项目配置、分析运行、代码事实、业务快照、文档修订、资源、审核和发布记录。
- 常见密钥、令牌、密码和授权头在进入快照、持久化、模型输入和错误记录前脱敏。
- 配置文件不得保存真实 API Key、App Secret 或访问令牌。
- 企业源码是否可以发送给模型供应商必须由使用者在启用真实 AI 前确认。

## 当前非目标

- Web 管理端、自动登录和页面遍历截图、RAG、Git 增量分析、独立 Help Center、多租户和生产知识库发布。
- npm 在线分发；当前全局命令只用于本地开发链接。
- 自动替代产品或业务评审、自动修改业务源码、自动判断截图中的敏感信息。
