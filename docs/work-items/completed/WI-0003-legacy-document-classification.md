# WI-0003 为旧版已审核文档补充系统和业务模块归类

## 结果

`v0.1.0` 中已经审核、可能已经发布且包含人工修订和截图的文档，可以在不重新调用 AI、不覆盖历史修订的前提下补充所属系统和业务模块，并通过正常预览、审核和分层发布流程继续使用。

## 背景

`WI-0002` 为新文档增加了系统/业务模块分类，并在发布前拒绝没有分类的旧修订。当前错误提示要求重新生成文档，会丢失旧文档中的人工修订、截图关联和审核历史，也给已有飞书页面的迁移带来不必要风险。

完成性终审发现，旧生成链路中的占位模块名称“未分类”仍可能被当作有效分类发布，且归类命令会把它误判为已经归类。工作项于 `2026-08-24` 临时重开，补充发布门禁和可修复路径，并将真实钥匙串验收证据补入 WI-0002 后重新关闭。

## 范围

- 新增 `bizdoc documents classify` 命令，交互选择已批准且未归类的文档，并确认业务模块。
- 非交互模式支持显式文档 ID、模块名称和可选稳定模块 ID。
- 从最新的已批准旧修订创建 `N+1` 修订，保留正文、证据、来源、截图和原历史修订。
- 新修订增加系统/模块分类以及阻塞式归类确认项，状态为 `needs_review`。
- 生成新修订的 Markdown，并要求按现有 `preview`、`review approve`、`publish feishu` 流程继续。
- 缺失、空白或名称为“未分类”的模块均视为待归类；发布必须在读取飞书凭证或访问网络前拒绝这些占位值。

不包含已经具有真实系统/业务模块分类的文档重新分类、模块批量重命名、远端失效映射修复或自动推断业务模块。

## 约束

- 不修改或重新批准旧修订，不复制旧审核解决记录到新修订。
- 不调用 AI，不访问飞书，不从 Controller、路由或源码名称猜测业务模块。
- 新修订前检查其引用的全部截图资源存在且可读；失败时不得创建修订或 Markdown。
- 非交互模式存在多个候选时必须提供 `--document`；模块必须由 `--module` 或项目中明确配置的 `default_module` 提供，不静默使用“未分类”。
- 已经带真实分类的最新修订必须拒绝迁移；空白或“未分类”模块属于可修复的占位分类，其他重新分类留给后续独立工作项。

## 实施方案

在应用层增加独立归类用例，负责读取和校验旧修订、资源预检、稳定分类 ID、Markdown 渲染与不可变修订保存。CLI 只负责工作空间发现、候选选择和参数收集，复用现有文档选择与项目配置。归类确认作为新修订的 blocking 审核项，由现有审核机制显式解决。

## 验收标准

- 旧批准修订的模型和状态保持不变，新修订完整保留文档内容与截图且状态为 `needs_review`。
- 新修订在批准前无法发布，批准后可进入现有发布流程。
- 缺失截图、非批准文档、已具有真实分类的文档和重复迁移均失败且不产生新修订；已存占位模块可创建待审核归类修订。
- 缺失、空白或“未分类”模块在任何飞书凭证读取和网络访问前阻塞发布。
- 操作不需要 AI 凭证、飞书凭证或网络访问。
- CLI 交互和非交互行为有自动化测试，README 给出升级步骤。
- 定向测试和完整 `pnpm check` 通过。

## 证据

- 应用层测试覆盖：旧批准修订和截图记录保持不变；新修订保留来源、正文和截图；缺失或不可读截图时不创建修订或 Markdown；未批准文档、目标模块为空或“未分类”、空模块 ID 和重复迁移均被拒绝，已存空白或“未分类”模块可归类修复。
- CLI 测试覆盖：唯一候选自动选择、多候选非交互阻塞、显式文档和模块、配置默认模块、无需外部凭证以及旧命令兼容；缺失、空白和“未分类”模块均先返回 `DOCUMENT_CLASSIFICATION_REQUIRED`，且不产生发布记录。
- 在真实 CRM 试点工作空间将一篇 v0.1 已批准文档迁移为分类修订；结构化比较确认除修订号、分类和新增审核项外内容完全一致，旧批准修订保持不变。
- 分类修订审核后在飞书测试知识空间连续发布两次，均复用原文档节点与链接；只读分页 API 确认同级系统、模块和文档各恰好 1 个。
- 已登录飞书页面确认“销售 CRM/线索管理/线索转化操作说明”面包屑和目录正确，正文、原生表格与两张业务截图均正常加载。
- `2026-08-24` 完整 `pnpm check` 在允许预览测试绑定 `127.0.0.1` 的环境中通过：19 个测试文件、115 个测试，以及文档检查、lint、类型检查和构建全部通过。

## 残余风险

- 当前命令只处理缺少分类或带空白/“未分类”占位模块的旧文档；真实分类的重新分类和模块批量改名需独立工作项。
- macOS 文件选择器和区域截图仍只有契约测试，没有真实 GUI 端到端测试。
- 并发发布和远端失效映射修复仍需后续工作项。
