- Umi/React 请求能够与 Spring Controller 端点关联。
- 每条关联保留前后端文件、Commit、符号和行号证据。
- HTTP Method 不一致不会误关联。
- 一个请求匹配多个后端端点时输出冲突，不静默选择。
- 大型 Java 文件无法由当前 Tree-sitter 组合处理时降级并计量，不标记为完整 verified。
- 真实候选能够生成不可变 DocumentationModel 和 Markdown 修订。
- 三个试点均已形成页面 → Controller → Service → Data Access → 主要对象的可审查路径：线索转化关联线索、转换记录和项目；项目发起评审关联项目；角色维护关联角色、角色成员和角色范围。155 条后端引用全部通过文件、Commit 和行号存在性复核。

- 新文档包含阻塞审核项，不能直接发布。
- “线索转化”已聚合四个写接口并形成首份金标草案，明确记录状态条件、必选客户、可选项目和失败分支。

## 4. AI 试点评测

| 检查项 | 修订 9 结果 |
|---|---|
| 事实准确性 | 覆盖 `lookupLead` 失败不阻塞、项目失败留在第二步、状态回写、转换记录成功码和客户 ID 缺失中止；仍待 CRM 研发逐条确认 |
| 步骤覆盖 | 4 步覆盖客户处理、可选项目、线索状态回写、转换记录和成功关闭，并描述项目跳过及部分失败分支 |
| 无证据陈述 | 所有引用 ID 均来自 Feature 或本次实际发送的补充事实；业务表述仍需人工确认，标题仍含组件名 |
| 审核门禁 | 自动加入 blocking review item，数据库状态为 `needs_review` |
| 稳定性 | 普通文本、直接 JSON 和 `tool_use` 均验证成功；复杂 Schema 输出存在字段遗漏和身份回传波动，加入有限机械修复、补充证据白名单及最多 3 次重试后成功生成 |

修订 9 已证明当前兼容接口可以完成完整结构化生成，但单次输出仍不稳定。系统只修复空集合和中性步骤标题，任何非法证据、不可变身份或业务字段类型仍会拒绝；批量生成前仍应测量重试率、延迟和人工修改成本。

## 5. 当前质量缺口

- 部分候选标题仍来自组件名或 Java 方法名，不是可直接发布的业务名称；线索转化已验证可通过页面调用上下文改善聚合粒度。
- 静态事实尚未完整连接页面操作顺序，模板步骤必须人工确认。
- Service 方法链路扩展曾出现两次过度关联：首次按整个 Service 类扩展使线索转化达到 665 个后端引用；递归所有本地调用时达到 327 个并引入无关权限对象。两次快照均未提升为基线。最终实现只保留可达数据访问的本地调用并限制一层展开，线索转化/项目评审/角色维护分别为 106/71/35 个后端引用。
- 第一版干净环境计时编排误执行了三次分析，临时目录内流程本身成功但时序未采用；修正编排后仅执行一次并记录上表正式结果，两个临时目录均已清理。
- 41 个大型或复杂 Java 文件需要评估 Tree-sitter 升级、分段策略或 JavaParser Sidecar。
- 三个最终试点均已完成真实 AI 样例：线索转化修订 9，项目发起评审和角色维护 AI 修订 7；后两篇进一步形成带业务标题和脱敏截图的整合修订 8。人工修改时间尚未测量。
- 用户已为项目发起评审和角色维护提供真实截图；系统生成脱敏副本，并在整合修订 8 中合并真实 AI 内容、业务标题和截图。两份本地预览只绑定 localhost，图片分别嵌入对应操作步骤。线索转化仍缺独立真实截图。
- 线索转化修订 8 已首次真实发布到飞书测试知识库：复用部分失败留下的节点，写入 22 个 Block，本地审计为 completed。
- 首次发布序列共 4 次尝试：路径错误、正文权限缺失等 3 次失败均被记录为 failed，权限修复后第 4 次成功；最终成功率为 1/4，首次完整发布结果为成功。
- 当前无截图，因此尚未验证真实图片上传和图片位置；表格 Block 仅有本地契约测试，本次文档没有字段表格。

## 6. 阶段结论

当前结论为 `CONDITIONAL_GO`：代码事实提取、跨栈关联、中间模型、Markdown、审核门槛和飞书适配器的本地技术路线成立。要将 MVP 判定为 `GO`，仍需完成：

1. 解决当前模型兼容接口的结构化输出稳定性，并完成其余 4 个候选的金标评测。
2. 用户已担任研发和业务评审人，仍需填写三个试点的逐条评审结论并确认业务功能名称、入口、步骤和结果。
3. 项目发起评审和角色维护已有脱敏截图；线索转化仍需至少一张真实截图。
4. 用户已授权一次重复发布验证；当前进程仍需安全注入飞书凭证后执行。
5. 对重复发布、图片位置和飞书排版进行人工验收。
