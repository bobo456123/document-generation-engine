## v0.1.1 - 2026-08-24

- 提供可通过 `pnpm link:cli` 安装的本地全局 `bizdoc` 开发入口，并从当前目录向上自动发现工作空间。
- 提供 macOS Keychain 凭证管理、环境变量优先级、配置诊断以及功能、文档和状态查询命令。
- 支持按名称交互选择功能、文档和步骤，通过系统文件选择器或 macOS 交互截图直接导入图片。
- 配置 AI 后默认生成真实 AI 文档，并保留 `--template` 作为明确的本地证据模板模式。
- 新文档记录系统/业务模块分类；飞书按“系统/业务模块/文档”幂等创建层级，并移动而非重建既有根目录文档。
- v0.1 已审核旧文档可通过 `documents classify` 保留正文、截图和历史修订，创建仅补充分层信息的待审核修订。
- 缺失、空白或“未分类”模块不得发布到飞书，并可通过 `documents classify` 创建新的待审核归类修订进行修复。
- 配置拒绝内嵌凭证；钥匙串通过标准输入安全写入，多字段更新失败时回滚，发布在任何飞书写入前完成审核和截图资源预检。
- 飞书节点创建及按索引删除旧正文不盲目重试；层级恢复覆盖分页查找和重名阻塞。
- 保留 v0.1 数据库、旧修订和历史发布记录，并为分层发布新增远端节点映射。
- 保留显式目录和旧版截图、审核、发布命令一个兼容周期。

完整证据见 [WI-0002](./work-items/completed/WI-0002-cli-usability.md) 和 [WI-0003](./work-items/completed/WI-0003-legacy-document-classification.md)。

## v0.1.0 MVP - 2026-08-23

验收结论：`GO`

- 建立 Node.js Monorepo、NestJS 应用编排层和 CLI 主入口。
- 支持只读解析 Spring Boot 与 Vue、React、Umi 项目，并生成可追溯业务功能模型。
- 支持证据模板或真实 AI 生成结构化业务操作文档和 Markdown。
- 支持手工导入脱敏截图、本地预览、不可变修订和阻塞式人工审核。
- 支持将已批准修订幂等发布到飞书测试知识空间，包括原生表格和图片。
- 完成三个真实 CRM 试点及飞书页面验收。

完整记录见 [v0.1 MVP 里程碑](./milestones/v0.1-mvp/README.md)。
