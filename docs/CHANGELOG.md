## v0.1.0 MVP - 2026-08-23

验收结论：`GO`

- 建立 Node.js Monorepo、NestJS 应用编排层和 CLI 主入口。
- 支持只读解析 Spring Boot 与 Vue、React、Umi 项目，并生成可追溯业务功能模型。
- 支持证据模板或真实 AI 生成结构化业务操作文档和 Markdown。
- 支持手工导入脱敏截图、本地预览、不可变修订和阻塞式人工审核。
- 支持将已批准修订幂等发布到飞书测试知识空间，包括原生表格和图片。
- 完成三个真实 CRM 试点及飞书页面验收。
